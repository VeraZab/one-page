## What each column measures

- **SWE-bench Verified** — resolving real GitHub issues end to end. The closest
  thing to "can it do the actual job."
- **Aider Polyglot** — editing existing code correctly across many languages.
  Rewards precise diffs, punishes confident nonsense.
- **LiveCodeBench** — fresh competitive-programming problems, so there's no
  training-set leakage. Raw problem-solving.
- **Terminal-Bench** — getting things done in a real shell: running commands,
  reading output, recovering from errors.

## How this gets built

The plan: a small daily job reads the current standings from each public
leaderboard, normalizes them to a rank per benchmark, and writes a dated data
file this page renders. History gets kept, so the table can eventually show
movement — who climbed, who slipped — not just a single day.
